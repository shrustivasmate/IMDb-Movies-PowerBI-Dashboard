# IMDb Movies Power BI Dashboard

This project is a Power BI dashboard built using an IMDb movies dataset. The goal of the dashboard is to explore movie data and present key insights through interactive visuals.

## Dashboard includes

- Total number of movies
- Average movie rating
- Total votes
- Average runtime
- Average movie rating by movie
- Movie count by genre
- Movie count by year of release

## Filters

The dashboard includes slicers to filter the report by:

- Director
- Genre
- Year of Release

## Tools Used

- Power BI
- Power Query
- DAX
- CSV Dataset

## Files

- IMDb_Movies_PowerBI_Dashboard.pbix
